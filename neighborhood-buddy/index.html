📡 Signal sources

🌤️ NWS Alerts API

Official, documented, no auth. Polled for both addresses — includes Red Flag Warnings, the critical Fiddletown fire-season signal. Verified live Oct 12, 2026.

weather.gov →

🚔 CHP incidents

Statewide active incidents, filtered by center: GG for San Jose, ST for Amador County. I poll the machine XML feed (media.chp.ca.gov/sa_xml/sa.xml); for tapping, use the live incident map:

cad.chp.ca.gov — CHP incident map →

🔥 Cal OES evacuations + CAL FIRE perimeters

Public ArcGIS REST, no key. Point-in-polygon checks per address; every 15 min in fire season. Live incidents: fire.ca.gov/incidents →

💡 PG&E outages

Public ArcGIS services behind the outage map (unofficial — treat endpoints as fragile). Polls every 15 min; PSPS watch in fire season. (Provenance: the outagewatch open-source project polls the same services.) For tapping — address search + restoration estimates:

PG&E Outage Center — live outage map →

👮 Amador Sheriff press releases

HTML scrape of the Sheriff's news page — no feed exists. Polled daily, plus the Amador County OES page.

amadorsheriff.org →

🚓 SJPD notifications

The SJPD news email subscription is the cleanest automated input for San Jose police news — CrimeMapping has no API. Nextdoor is login-walled (out of scope for v1).

🏘️ Nextdoor — San Jose patch (LIVE)

Read-only pulse on Almaden - Williams and the 25 followed Almaden Valley neighborhoods, under the adopted charter. Triage bar: crime, lost pets, Almaden-route closures, outages, 95120 city decisions, fires. Everything else stays noise.

📻 Radio / scanner

The neighborhood pulse you can hear: sheriff/fire/EMS frequencies for both zones — Amador County is all analog (handheld-friendly), San Jose is mixed analog + P25 trunked. Includes the Fiddletown check-in net. Full tables in the dossier →

🌅 Morning digest → evening briefings

Findings are deduplicated, scored for safety relevance, and compiled into a morning digest (overnight activity). Intraday alerts fire only for genuinely urgent items — evacuation orders/warnings, Red Flag Warnings, major closures on Dave's corridors, PSPS events. Quiet days produce a one-line all clear. The digest feeds the morning and evening briefings automatically.
