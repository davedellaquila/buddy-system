🔑 GitHub token needed to save

Saving writes the settings file to the buddy-system repo on GitHub, which needs your GitHub token — the same one the buddy pages already use (stored only in this browser, under the shared buddyTree store). Create one at github.com/settings/tokens/new — a classic token with the repo scope. Without a token, your settings still save on this device and send automatically once a token is added — nothing is lost.
