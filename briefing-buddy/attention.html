This is the front page of the Briefing Buddy homepage for a reason: everything here is waiting on Dave. Each card is a decision, a review, or a loose end. Tap ✓ Done when it's settled, or Need more info and the buddy follows up.

How it works

Two buttons, no inbox

Every attention card carries ✓ Done and Need more info. Tapping either writes a timestamped entry to docs/ingest.md in the buddy's private repo (davedellaquila/briefing-buddy) via the GitHub API — the same write path as the brain-dump box. Marking something done tells the buddy to clear it from the list; asking for more info asks the buddy to follow up with Dave.

Done state persists on the device (localStorage), so a card you cleared stays cleared when you come back.
