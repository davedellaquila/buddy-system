🔑 This is what bit you: your browser kept a saved copy of Nan's page from before the dump box existed, and showed you that instead of fetching the new one. The Muse app had never opened it, so it fetched fresh. Fix: hard refresh (or the dashboard's "Update now" banner, which busts the cache).

No token on a device → the box shows the disabled "Connect GitHub to enable" state instead of a dead form. Read-only viewers never have a token, so they never get a working box.
