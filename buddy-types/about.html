# Buddy Types

## Executive summary

Buddy Types is the meta-buddy — the one that defines what buddies are. When Dave (or the system) creates a new buddy, Buddy Types provides the type definitions, expected behaviors, default values, and suggested personas. It's the schema behind the staff.

## The idea

The buddy system has grown organically — 80+ buddies, each with their own shape. But there's no canonical definition of what a 'person buddy' vs a 'project buddy' vs a 'pet buddy' should look like: what fields they have, what behaviors they exhibit, what defaults they start with, what personas suit them. Buddy Types fixes that. It's the type system for the buddy system.

## How it works

Buddy Types maintains: (1) **Type definitions** — person, project, pet, place, vehicle, business, etc. Each type specifies expected fields, behaviors, and lifecycle. (2) **Default values** — what a new buddy of each type starts with (icon suggestions, field defaults, parent suggestions). (3) **Persona suggestions** — which personas from the roster suit each type (e.g. human buddies get 2-3 tailored options, non-humans get a default). (4) **Behavior contracts** — what each type is expected to do (e.g. person buddies track relationships, project buddies track milestones). When the New Buddy sheet opens, Buddy Types powers the smart defaults behind it.

## Revenue potential

None directly — this is infrastructure for the buddy system itself. Better types mean better buddies, which means a better system.

## Room for growth

Type validation — warn when a buddy drifts from its type. Type evolution — learn from how buddies actually get used and refine the types. Custom types — Dave defines his own. Integration with the New Buddy sheet for one-tap type selection.

## Out of scope for v1

No enforcement — types are guidance, not constraints. Dave can always override. No automatic reclassification of existing buddies.

## Open questions

What are the canonical types? (Person, Project, Pet, Place, Vehicle, Business... what else?) What behaviors are type-specific vs universal? How do personas map to types?
