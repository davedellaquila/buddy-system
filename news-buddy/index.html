DeepMind and Singapore built an on-device AI that spots scams without phoning homethin sourcing

Unveiled in a DeepMind blog post on Oct. 14 and presented at Singapore International Cyber Week, the model — a fine-tuned version of Google’s lightweight Gemma, trained on local scam conversations including impersonations of public institutions, banks, and local figures — screens smartphone conversations for manipulation patterns entirely on-device. Neither Google nor the Singapore government can view the conversations.

Engineering

Next.js security update: two critical RCEs patched, no workarounds

Vercel shipped an out-of-band Next.js security update on October 14, patching three vulnerabilities via Next.js 16.4.1 (Active LTS) and 15.5.28 (Maintenance LTS). Two are critical unauthenticated remote code execution flaws: GHSA-673q-mjm6-r5xr, triggered when an App Router ’use cache’ function returns multiple typed arrays (no workaround — upgrade immediately), and CVE-2026-96889, a memory bug in the upstream sharp image library affecting the Image Optimization API with SVGs on glibc-based Linux. The third, GHSA-p3m5-59mp-jv5r, is a high-severity Server Actions denial-of-service via crafted requests that exhaust CPU. Every 16.3 release, including 16.3.8, is affected — 16.3 users must move lines.

Next.js · Oct 14

SlugFest: npm trusted-publishing flaw exposed 1,500+ packages to takeover

Bloom Security’s Golan Myers disclosed ’SlugFest,’ a flaw in npm’s OpenID Connect trusted publishing: configurations trusted a repository name rather than GitHub’s immutable repository ID, so an attacker could reclaim an abandoned GitHub repo slug and publish malicious versions under the legitimate package name — with a valid provenance signature. Bloom found over 1,500 vulnerable packages with more than 10 million combined downloads. GitHub validated the report in June and on October 2 introduced the 48-hour expiry: unvalidated publisher configs now expire 48 hours after creation, and npm blocks OIDC token exchange from issue_comment workflows. Myers notes AI coding agents make this class of flaw reach further — agents install ~70 packages/month on a typical endpoint without reviewing them.

Help Net Security · Oct 13

TanStack Start 1.0 is stable — the client-first full-stack alternative

TanStack declared TanStack Start 1.0 stable on October 13, formally committing to stable APIs for its full-stack React (and Solid) framework after a long RC period — the post notes enterprise teams and Fortune 500 companies insisted on running it in production even while it was in beta. Highlights: end-to-end type-safe routing, per-route rendering modes, typed createServerFn server functions, and a reported ~5.5x SSR throughput gain from profiling work. Agent-ready by design: packages ship TanStack Intent skills so AI agents learn Start’s APIs and best practices. RSC support exists but is opt-in.

TanStack · Oct 13

GitHub rewrote Copilot’s runtime in Rust with AI help: 5.25s to 292mssecondhand

GitHub migrated the runtime behind the Copilot CLI, Copilot app, and Copilot SDK from TypeScript/Node.js to Rust in an AI-assisted rewrite: over 800,000 lines of production code replaced in roughly 14.5 weeks across 128 pull requests, delivered incrementally with temporary NAPI interop so existing end-to-end tests kept exercising new code. The headline number: a measured startup/session/single-turn scenario dropped from 5.25 seconds to 292 milliseconds, and embedding via a C ABI eliminates the ~100 MB of working set per client the old process-boundary design required.
