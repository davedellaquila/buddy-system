AI & Technology

Anthropic names China’s Z.ai as a Claude copycat, says new defenses cut data theft 90–99%

In a research post Monday, Anthropic said new safeguards that restrict access to Claude’s step-by-step reasoning have reduced data harvested in so-called distillation attacks by about 90% to 99%, with reasoning tokens extracted now 10 to 100 times lower than before. The company banned tens of thousands of linked accounts and named Chinese startup Z.ai (Zhipu) as a company that tried to distill Claude’s capabilities while building its GLM-5.3 model, warning the practice poses safety and national-security risks. Z.ai did not immediately respond to a request for comment.

Meta’s Muse Wonder arrives: first frontier model since the Alexandr Wang reboot

Meta’s Superintelligence Labs unveiled Muse Wonder and Muse Wonder Full on Oct 12, calling them the company’s first genuinely frontier-class models since Llama 4 — trained at the Prometheus data center in Ohio with a 1M-token context window. Wonder sells via the Meta Model API at $4/$20 per million input/output tokens; the stronger Wonder Full is restricted to $50–$200 Muse Code subscriptions. Zuckerberg told the Financial Times the launch brings Meta ’to the frontier’ and rejected calls for a coordinated industry slowdown; Meta stock rose more than 3% on the news.

Harvard study: AI coding agents add 30% more code, but shipped output is flatsecondhand

Harvard economists Fiona Chen and James Stratton analyzed ~300M work events across 700,000+ employees at 700+ firms via Jellyfish data, as first reported by Ars Technica on Oct 9. After agent adoption, lines of code rose 30%, commits 20%, and PRs 23% — but resolved Jira issues/epics didn’t move, because PR review time rose 49%, change requests nearly doubled, and 14% more workers shifted into review. No measurable employment change either.

GitHub adds 48-hour expiry to unvalidated npm trusted-publishing configsthin sourcing

Following a Bloom Security investigation (reported to GitHub on June 6, 2026), GitHub is closing a supply-chain loophole where attackers could claim abandoned repository slugs and publish package updates without credentials. Unvalidated trusted-publishing settings now expire automatically 48 hours after creation, becoming permanent only after a successful publish. The research flagged over 1,500 vulnerable packages with 10M+ combined downloads; npm also now rejects requests from certain automated bot processes.
