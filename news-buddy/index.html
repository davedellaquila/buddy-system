The human job moves up the stack: as agents absorb line-by-line typing, engineers absorb architecture, verification, security auditing and coordination — Lamanna’s Ignite interview, in full

Windows Forum’s long read of the Behind the Craft interview: agent-started PRs modified multiple files about 87% of the time (vs. 79% for human PRs), and repositories with an agent configuration file averaged eight times as many commits as those without.
