Frothier

Supreme Court rejects Trump’s bid to set aside 20,000 California ballots — no noted dissent, hours before Election Day

USA Today, Nov. 2: the Supreme Court declined the Justice Department’s emergency request to force California to segregate mail ballots from about 20,000 registered voters the administration alleges may not be citizens, with none of the justices publicly dissenting. District Judge David Carter had called it unprecedented for the federal government, on an election’s eve, to coerce a state to abandon its own procedures; the 9th Circuit (2-1) said forcing use of the federal list could bar valid votes and jeopardize Los Angeles County’s election. A UCLA Voting Rights Project analysis found about 42% of the names on the federal list did not match anyone in California’s voter file. The underlying lawsuit continues; today’s ballots are counted under California’s existing procedures.

PBX Science

Node2Shell (CVE-2026-111497): the Brotli flaw inside Node.js is exploited in the wild — fixed in 22.23.4, 24.22.2 and 26.12.1; Node 20, 23 and 25 got no fix

Sentilio’s guide: a memory flaw in Brotli, the compression library built into Node.js, lets an attacker run code on a server by sending compressed data the app unpacks — no login needed. Affected: Node.js 22, 24 and 26 before the Oct. 21 releases, and Node 20, 23, 25 and older, for which no fix was released. Fix: update to 22.23.4, 24.22.2 or 26.12.1 or later, restart, and rebuild container images — a pinned Docker tag such as node:24.22.0 stays vulnerable, and blocking Brotli at a proxy does not protect fetch() calls. ELLIO reported exploit traffic aimed at Node 24.22.0 on Oct. 26; CISA added the flaw to the KEV catalog Oct. 27.

Tomorrow, Nov. 4: GitHub’s first SSH brownout — legacy ssh-rsa (SHA-1) and an old Diffie-Hellman method go dark briefly ahead of permanent removal Jan. 13, 2027

TechnologyHQ’s checklist, carried to its action day: GitHub retires RSA signatures using SHA-1 and the diffie-hellman-group-exchange-sha256 key exchange, with brownouts Nov. 4 and Dec. 9 and permanent removal Jan. 13, 2027. Since Oct. 14, newly uploaded RSA keys must be at least 3,072 bits. Most modern clients already speak SHA-2 RSA and need no new key; HTTPS remotes are out of scope.
