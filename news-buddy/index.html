Binance, day three: $6.34 billion set aside to make users whole, about $3 billion frozen, withdrawals still paused with a phased restart targeted

ANI, Oct. 31, on Binance’s second recovery update: the exchange has secured about $5 billion in the same tokens stolen (roughly 80% of the $6.3 billion drained at 20:05 UTC on Oct. 29) and is buying the rest on public markets and OTC, funded by its SAFU fund and corporate treasury. About $3 billion of the stolen assets are frozen with partners; Tether froze nearly $1.57 billion and Circle $800 million — but 18,270 stolen bitcoin, now split across 19 wallets, cannot be frozen. Withdrawals remain paused with a phased resumption targeted within about 34 hours, subject to security checks; a proof-of-reserves report is due Monday, Nov. 2. Binance now says the compromised laptop was not the only intrusion point.

One line to say no: OpenAI, Google, Microsoft and Anthropic back a unified AI-training opt-out token in robots.txt

Engadget, Oct. 31: the four labs will honor a single shared signal — a User-Agent: __usage_ai-training block in robots.txt — so publishers set one training preference instead of separate rules per crawler. The proposal is an IETF individual draft authored by Anthropic’s Kevin Kelley, dated Oct. 30 and expiring May 3, 2027. Anthropic already honors it; Microsoft starts Feb. 1, 2027; Google follows in 2027; OpenAI in the coming months. It does not block search crawling, and it cannot undo past scraping. Meta expressed support without committing.

Engineering

Fragnesia deadline day: the kernel half of the PHP2Shell chain is due TODAY, Oct. 31 — forensic triage first, then a fixed running kernel

Safeguard’s KEV analysis: CVE-2026-46300, public since May, is a flaw in how socket buffers merge that lets the IPsec ESP code decrypt in place over page-cache memory — so a local user can alter files they may only read, and become root. CISA added it to KEV on Oct. 28 with today’s due date and forensic triage flagged, writing that it ’can be chained with CVE-2026-109618 and CVE-2026-109619 to implant PHP webshells and run commands as root.’ The PHP flaws give code execution as the web user; Fragnesia finishes the climb. Patching PHP alone — deadline Oct. 29, fixed builds 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35 — leaves root on the table; the kernel closes only with a fixed kernel actually running.

Safeguard.sh

DataWater’s threat desk, Oct. 30: CISA added eight exploited vulnerabilities to the KEV catalog between Oct. 24 and 30 — the PHP2Shell pair, Adobe Commerce/Magento (CVE-2026-48356), Google Brotli (CVE-2026-111497), the Linux kernel’s Fragnesia, VMware ESX (CVE-2026-41709), GitLab (CVE-2026-97229) and Cisco Secure Firewall ASA/FTD (CVE-2026-76418), two a day Monday through Thursday.
