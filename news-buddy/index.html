AI coding agents add 30% more code, not more softwarethin sourcing

A Harvard study across 700+ firms found developers with AI coding agents write roughly 30% more code — yet shipped issues don’t budge. Commits rose ~20% and PRs ~23%, but issue and epic resolution rates barely moved. The researchers’ diagnosis: human code review is now the chokepoint, and it hasn’t widened just because the code got bigger. Same week, Microsoft unveiled a redesigned Copilot built around three surfaces.
