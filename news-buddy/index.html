A global AI briefing’s Nov. 2 lead: OpenAI (Oct. 26) and Anthropic (a day later) each announced proofs disproving the Exponential Time Hypothesis — the longstanding premise that 3-SAT cannot be solved quickly — with both models arriving at the identical bound 2^(n/sqrt(log n)) on Oct. 16 and formalizing results in the Lean proof verifier. Engineering

Hackers target 61 GitHub repositories with command-injection attacks to steal CI/CD secrets: 83 malicious issues and PRs in 43 minutes

Cybersecurity News, Nov. 2, on Radware’s investigation: attackers posted 83 malicious issues, pull requests and comments on Sept. 1 — 77 within about 43 minutes — placing Bash $() command-substitution payloads in user-controlled text that workflows pasted directly into shell scripts. Targets included Google LangExtract, Trivy, Brave Browser, MLflow, ToolJet and PX4-Autopilot; every verified payload pointed to one server on port 8443, with a separate collection ID per attempt. Execution inside two workflows was confirmed; GitHub Actions secrets are not automatically available to every workflow, so execution alone does not prove credentials were stolen.

Cybersecurity News

GitHub SSH security changes: first brownout Nov. 4 for legacy ssh-rsa (SHA-1) and an old Diffie-Hellman method, permanent removal Jan. 13, 2027

TechnologyHQ’s checklist, Nov. 2: GitHub retires RSA signatures using SHA-1 and the diffie-hellman-group-exchange-sha256 key exchange, with brownouts Nov. 4 and Dec. 9 and permanent removal Jan. 13, 2027. Since Oct. 14, newly uploaded RSA keys must be at least 3,072 bits, and a hybrid post-quantum exchange (mlkem768x25519-sha256) is enabled in specified environments. Most modern clients already speak SHA-2 RSA and need no new key; HTTPS remotes are out of scope. Check CI runners and old automation before Wednesday’s brownout.

TechnologyHQ

CVE-2026-97229: Alpine’s GitLab update missed the Ruby fix — a CVSS 10.0 Onigmo overflow, exploited in the wild, CISA-listed Oct. 29single-author analysis

TrickyWorld’s Nov. 2 write-up: Alpine’s GitLab 19.3.6 upgrade still shipped a vulnerable Ruby — CVE-2026-97229, an integer overflow in Ruby’s Onigmo regex engine enabling unauthenticated RCE, scored 10.0 by GitLab and in CISA’s Known Exploited Vulnerabilities catalog since Oct. 29, with FIRST estimating a 27% exploitation chance in the next 30 days. Official fixes are GitLab 19.2.8, 19.3.5 and 19.4.2, and custom images also need Ruby 3.3.13, 3.4.12 or 4.0.9 or later; Alpine 19.3.6 images pulled before Oct. 27 remain vulnerable and must be pulled again. Six public PoC repositories are explicitly unverified — some are fake or malicious.
