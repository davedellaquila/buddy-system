Engineering

UnrealIRCd's label-tag flaw is in CISA's KEV with a Monday Nov. 16 federal deadline — exploitation is live

CISA added CVE-2026-114713 (CVSS 8.6) to the Known Exploited Vulnerabilities catalog Nov. 13 with a Nov. 16 federal remediation deadline. An IRCv3 label-tag escaping flaw in the labeled-response module lets any ordinary user on a network with two or more linked servers inject server-to-server commands with server authority. It affects 6.0.0–6.2.7 (and end-of-life 5.x) and is fixed in 6.2.7.1, released Nov. 7, which closed nine flaws in total. Maintainer Bram Matthys called it the most critical UnrealIRCd issue in 15 years.

Hacker Posts

Apache 2.4.71 patches the critical mod_http2 race (CVE-2026-119618) — found by Anthropic's scanner and Google Cloud researchers

Apache released HTTP Server 2.4.71 on Nov. 11 fixing CVE-2026-119618, a race and heap-corruption flaw in mod_http2's assign_headers() that Apache rates critical and Red Hat scores 9.8; unauthenticated remote code execution is possible only where HTTP/2 is enabled. It affects 2.4.55–2.4.70 and standalone mod_h2 2.0.8–2.0.42; HTTP/1.1-only servers are unaffected. The flaw was reported by Anthropic's OSS Scanner (Oct. 26) and Google Cloud Vulnerability Research (Nov. 3); no confirmed in-the-wild exploitation as of Nov. 14, and scoring differs by source (Red Hat 9.8 vs CISA enrichment 8.1).

N-able N-central: a second Able2Shell round bypasses Hotfix 2 — 21 servers found mining Monero, no full patch yet

Follow-up to the Nov. 9 Able2Shell disclosure of 33 N-central zero-days: new chains 4EverAble2Shell and Agent2Shell work against the Nov. 10 Hotfix 2 build (2026.4.1.26) when the non-default Legacy API is enabled and internet-reachable, running commands as the nable user via the bundled Apache Axis, then escalating to root. Huntback counted 21 N-central servers mining Monero on Nov. 12, 19 of them on Hotfix 2. Mitigation: apply 2026.4.1.26, upgrade Agents and Probes, disable the Legacy API; a further Hotfix 3 was still in validation Nov. 14.
