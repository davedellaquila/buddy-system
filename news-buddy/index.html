COP31 goes into overtime: the new draft strips out fossil fuels and the $120 billion adaptation target — Panama threatens to block any deal without a transition path

Reuters from Antalya: the COP31 conference slipped past its Friday deadline as nearly 200 countries deadlocked over whether the final deal should mention fossil fuels at all, and over finance for poorer countries. Systems & security

Engineering

Patch now: OpenSSL hit by a critical 9.8 heap buffer overflow in its Base64 encoder — CVE-2026-121481, fixed in 4.0.4 and 4.1.1

Cyber Security News, via the security feeds: a heap buffer overflow in OpenSSL’s EVP_EncodeBlock() — CVSS 9.8, published Nov. 18 — can corrupt memory when an application passes very large untrusted inputs to the Base64 encoder. Affected: OpenSSL 4.0.0-4.0.3 and 4.1.0; fixed in 4.0.4 and 4.1.1; 3.x is outside the affected ranges in the CVE record. Ubuntu flags a trap: Node.js on 22.04 embeds its own OpenSSL copy, so checking only the system library misses bundled copies. The question for every team is the same: what untrusted data reaches your encoder?
