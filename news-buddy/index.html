Engineering

Claude Ship, dissected: three agents, strict separation of duties — Code Review comments, PR Steward fixes but can never approve, Claude Approvals signs off only under a .claude/approvals.yml policy

Windows Forum’s full read of Anthropic’s Nov. 23 beta: the architecture is the reassurance. Code Review (GA) posts severity-ranked comments and never blocks; PR Steward (beta) resolves failing CI, merge conflicts and review comments but is designed never to approve or merge; Claude Approvals (beta) evaluates diffs against the repo’s policy file and routes risky changes to humans, with GitHub branch rules still governing merges. Anthropic’s own Claude Code team is the case study: Claude writes most of the code, humans were stuck context-switching back into old branches.
