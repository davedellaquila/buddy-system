New-Project Manifest

What every new buddy automatically gets when it's born.

1 · Side threadThe project's conversational home — all discussion, decisions, and reviews live here.Automatic
2 · Product briefCanonical description in Zuki Docs (Google Doc): the idea, the problem, revenue potential, room for growth, v1 scope, open questions.Automatic
3 · GitHub repoPrivate repo holding the code — and eventually the knowledge base (KNOWLEDGE.md, DECISIONS.md).Automatic
4 · INIT summaryFirst message in the thread: the brief's executive summary (the mission statement), plus links to brief, repo, related docs, parent and children. Must include CRITICAL standing orders from AGENTS.md — especially dark mode for the buddy website.Automatic
5 · Review askQuick-reply widget asking Dave to review the brief — looks good, edits, or defer.Automatic
6 · Quick-links entryOne-tap link to the brief, appended to quick-links.md.Automatic
7 · Memory entryMEMORY.md bullet: what the project is, key links, current status.Automatic
8 · Awaiting-reply entryThe brief review tracked in the registry until Dave answers.Automatic
9 · Dashboard entryThe buddy appears here in the dashboard, in hierarchy order.Planned
10 · Per-buddy home pageA home page for the new buddy. CRITICAL: must ship a dark mode (prefers-color-scheme or equivalent) — not light-only. See AGENTS.md / docs/standing-orders.md.Planned
